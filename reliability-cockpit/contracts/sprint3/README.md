# Sprint3 proposed offline evidence contracts

These readiness/decision schemas are proposals for NADI qualification and Sprint4
handoff, not active shared collector contracts, source mappings or approvals.
They never read source systems, persist data, approve mappings or calculate KPIs.

Run: `python -m unittest discover -s reliability-cockpit/contracts/sprint3/tests -v`
from repository root. Examples are SYNTHETIC ONLY. Existing shared schemas remain
unchanged and continue their independent regression suite. Source-owner/engineer
approval is required before any future foundation adoption or operational use.
