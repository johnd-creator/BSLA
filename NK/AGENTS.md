# NK documentation boundary

Follow `../AGENTS.md`. This public directory contains documentation only; NK code,
model/scaler, training exports and private mappings are not bundled in main.
Read `README_WebApp.md` and `../plans/NK-ROADMAP.md` before any future NK work.

Use a solo developer loop in the actual owning checkout: inspect current changes,
edit a small useful unit, test proportionally and inspect results. Preserve other
work; no routine extra worktree, subagent team or handoff ceremony. Documentation
checks need no service restart, source collection or model execution.

NK remains a separate consumer, not the active NADI Laravel UI. No new DB,
duplicate collector, direct production PI/SQL, source credentials or implicit
collection/backfill. Read stored PI through its existing API only when authorized.
Preserve exact feature order, model/scaler pairing, explicit input mode, unit and
quality/age/time-alignment gates. No silent zero/manual substitution, guessed
PS/SFC/APH mapping or production-readiness claim. Keep private artifacts private.

Do not import unrelated NK source/model/data merely to make a documentation link
work. Publishing code, retraining, changing mappings or deployment is a separate
scope. Report checks actually run and unverified assumptions plainly.
