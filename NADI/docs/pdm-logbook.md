# Private-catalog PdM logbook

A reviewed private catalog supplies measurement-point definitions. Missing catalogs
remain unavailable. Tests use the synthetic fixture only; source workbooks and
extracted measurements are not shipped. Existing draft snapshots and fingerprints
are preserved. Engineer-owned drafts support explicit units, unknown context,
date-only or timezone-aware precision, repeat-submit protection and stale-edit
checks. No source assets, operational databases or source workbooks are modified.

See the workspace README for private path configuration and test commands.
